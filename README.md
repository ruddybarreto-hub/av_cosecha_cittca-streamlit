# Dashboard de Avance de Cosecha

Aplicación Streamlit para visualizar el avance de cosecha por propiedad.

Coloca `avance_cosecha.xlsx` en la misma carpeta que `app.py`.

Para ejecutar:
```bash
pip install -r requirements.txt
streamlit run app.py
```

El Excel puede ser reemplazado por la nueva exportación de QGIS; el procesamiento se recalcula automáticamente.
